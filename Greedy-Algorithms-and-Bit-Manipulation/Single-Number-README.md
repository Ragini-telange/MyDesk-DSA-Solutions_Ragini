## Problem Statement
Given a non-empty array of integers nums, every element appears twice except for one. Find that single one in linear runtime complexity and without extra memory.

### Input Format
First line contains n. Second line contains n integers.

### Output Format
Print single unique integer.

### Constraints
```text
1 <= nums.length <= 3 * 10^4
Each element appears twice except for one.
```


---

## Sample Test Case
**Sample Input:**
```text
5
4 1 2 1 2
```

**Sample Output:**
```text
4
```

**Explanation:**
XOR of duplicate numbers is 0; 4 ^ 0 = 4.
