## Problem Statement
Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.

### Input Format
First line contains n. Second line contains n integers.

### Output Format
Print 'true' or 'false'.

### Constraints
```text
1 <= nums.length <= 10^5
-10^9 <= nums[i] <= 10^9
```


---

## Sample Test Case
**Sample Input:**
```text
4
1 2 3 1
```

**Sample Output:**
```text
true
```

**Explanation:**
1 appears at index 0 and 3.
